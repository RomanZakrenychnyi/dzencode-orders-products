# Orders & Products

Тестовое задание DZencode на позицию Junior+ React Developer: приложение учёта приходов и товаров.

## Статус проекта

Подготовка к разработке. Сейчас добавлены только этот README и `.gitignore`. Приложение, зависимости, Docker-окружение и тесты ещё не настроены.

Описанные ниже функции и технологии — план реализации, а не перечень уже готовых возможностей.

## Планируемый функционал

- Страницы «Приходы» и «Продукты» с навигацией и анимациями переходов.
- Список приходов: название, количество товаров, дата в двух форматах и суммы отдельно в USD и UAH.
- Просмотр товаров выбранного прихода в боковой панели.
- Удаление прихода с подтверждением.
- Список товаров с фильтром по типу, сроками гарантии, ценами и названием связанного прихода.
- Отображение текущих даты и времени.
- Счётчик активных подключений приложения через Socket.io.
- Формы с проверкой введённых данных.

## Планируемые технологии

| Область | Технологии |
| --- | --- |
| Интерфейс и маршрутизация | React, TypeScript, Next.js App Router |
| Состояние и запросы | Redux Toolkit, React Redux, RTK Query |
| Стили | Bootstrap, SCSS, БЭМ |
| Формы и валидация | React Hook Form, Zod |

Совместимые версии зависимостей будут выбраны при настройке приложений и зафиксированы в файле блокировки зависимостей.

## Требования уровня Junior+

- TypeScript.
- Серверный рендеринг (SSR) средствами Next.js.
- Unit-тесты.
- Локализация интерфейса (i18n).
- Авторизация с JWT.
- Web Storage для настроек интерфейса.
- Отложенная загрузка компонентов (Lazy Loading).
- Графики (Charts).
- Карты (Maps).

Сценарии использования графиков и карт требуют уточнения: в ТЗ перечислены технологии, но не описано их поведение в приложении.

## Запуск и проверка

Команды установки, разработки, сборки и тестирования будут добавлены после настройки и проверки соответствующих инструментов. На текущем этапе запустить приложение нельзя.

При подготовке окружения здесь появятся:

1. Необходимые версии инструментов.
2. Инструкция по настройке переменных окружения через `.env.example`.
3. Команды запуска через Docker Compose и локального запуска для разработки.
4. Команды применения миграций и загрузки демонстрационных данных.
5. Команды проверки типов, линтера и тестов.

Локальные `.env`-файлы исключены из Git. Файлы примеров окружения должны содержать только демонстрационные значения без действующих секретов.

## Данные и схема БД

Основная связь: один приход содержит несколько товаров, каждый товар относится к своему приходу. Цены в USD и UAH учитываются отдельно.

Миграции, демонстрационные данные и модель БД для MySQL Workbench будут добавлены при реализации базы данных. Правила удаления связанных записей будут зафиксированы вместе с API.
