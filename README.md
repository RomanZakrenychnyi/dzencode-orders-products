# Orders & Products

Тестовое задание DZencode на позицию Junior+ React Developer: приложение учёта приходов и товаров.

## Статус проекта

Создана основа интерфейса на Next.js и TypeScript в `apps/web`. Подключены Bootstrap и SCSS, добавлены верхняя панель и боковое меню. На `/orders` отображаются четыре демонстрационных прихода: название, количество связанных товаров, дата в двух форматах и суммы USD/UAH. На `/products` отображается список товаров с фильтром по типу и счётчиком найденных позиций. Обе страницы доступны через меню; `/` перенаправляет на `/orders`. Активный раздел выделяется, при переходе используется анимация появления с учётом настройки уменьшения движения.

В списке продуктов показаны название, серийный номер, тип, начало и окончание гарантии в двух форматах, состояние, цены и связанный приход. Данные берутся из общего Redux-состояния: удаление прихода отражается и на странице продуктов. Для пустого списка предусмотрено сообщение, на узких экранах таблицу можно прокручивать по горизонтали.

По нажатию на название прихода открывается панель связанных товаров, а список становится компактнее. Панель закрывается крестиком или клавишей Escape при фокусе внутри неё. Для пустого прихода выводится отдельное сообщение. На узких экранах панель располагается под списком.

Подключены Redux Toolkit и React Redux. Корзина в строке прихода открывает окно подтверждения с названием и предупреждением об удалении связанных товаров. Подтверждение удаляет приход и его товары из общего состояния, обновляет счётчик и закрывает панель удалённого прихода. Отмена, крестик и Escape сохраняют данные. Изменения сохраняются при переходах между страницами, но после перезагрузки восстанавливаются демонстрационные данные.

Дата и время в верхней панели пока статические, поиск не подключён к данным. Разделы «Группы», «Пользователи» и «Настройки» отображаются без переходов. Сервер, Docker-окружение и постоянный набор тестов ещё не добавлены.

Описанный ниже функционал — план реализации. Таблица технологий включает как подключённые инструменты, так и запланированные.

## Планируемый функционал

- Страницы «Приходы» и «Продукты» с навигацией и анимациями переходов.
- Список приходов: название, количество товаров, дата в двух форматах и суммы отдельно в USD и UAH.
- Просмотр товаров выбранного прихода в боковой панели.
- Удаление прихода с подтверждением.
- Список товаров с фильтром по типу, сроками гарантии, ценами и названием связанного прихода.
- Отображение текущих даты и времени.
- Счётчик активных подключений приложения через Socket.io.
- Формы с проверкой введённых данных.

## Запуск и проверка

Требуются Node.js 24.x и npm 11.x. Все команды выполняются из корня репозитория.

Установка зависимостей по файлу `package-lock.json`:

```sh
npm ci
```

Запуск в режиме разработки:

```sh
npm run dev
```

Откройте http://localhost:3000. Если порт занят, сервер разработки сообщит другой адрес в терминале. Для остановки нажмите `Ctrl+C`.

Проверка типов:

```sh
npm run typecheck
```

Сборка и запуск собранного приложения:

```sh
npm run build
npm run start
```

Для текущей начальной страницы переменные окружения и база данных не требуются. Инструкции по Docker, миграциям, линтеру и тестам будут добавлены по мере их настройки.

## Текущая структура

```text
apps/web/
  src/
    app/
      layout.tsx     # Общий HTML-макет, метаданные и подключение стилей
      page.tsx       # Перенаправление с / на /orders
      orders/page.tsx   # Страница приходов
      products/page.tsx # Страница продуктов
    components/
      top-menu/         # Верхняя панель и её SCSS
      navigation-menu/ # Боковое меню и его SCSS
    styles/
      globals.scss   # Общие стили и собственные классы по БЭМ
  package.json       # Зависимости и команды интерфейса
  tsconfig.json      # Настройки TypeScript
package.json         # npm workspaces и общие команды
package-lock.json    # Зафиксированные версии зависимостей
```

Локальные `.env`-файлы исключены из Git. Файлы примеров окружения должны содержать только демонстрационные значения без действующих секретов.

## Стили

В корневом `layout.tsx` сначала подключается готовый CSS Bootstrap, затем собственный `globals.scss`. Bootstrap используется для сетки, отступов и базового оформления; собственные классы именуются по БЭМ, например `navigation-menu__item`.

SCSS компилируется Next.js с помощью пакета `sass`. Отдельная команда компиляции стилей не требуется. Сетка и отступы заданы Bootstrap, а фон, оформление меню и анимация страниц — собственными SCSS-стилями.

JavaScript-плагины Bootstrap не подключены. Поведение интерактивных компонентов будет реализовано средствами React.

## Данные и схема БД

Основная связь: один приход содержит несколько товаров, каждый товар относится к своему приходу. Цены в USD и UAH учитываются отдельно.

Текущие демонстрационные данные находятся в `apps/web/src/data/inventory.ts`, типы — в `apps/web/src/types/inventory.ts`. Товар связан с приходом через `orderId`. Денежные значения `amountMinor` хранятся целыми числами в центах/копейках; суммы вычисляются отдельно для каждой валюты, без конвертации. Приход без товаров показывает нулевое количество и нулевые суммы. Для отображения дат используется часовой пояс `Europe/Kyiv`.

Миграции, демонстрационные данные и модель БД для MySQL Workbench будут добавлены при реализации базы данных. Правила удаления связанных записей будут зафиксированы вместе с API.
